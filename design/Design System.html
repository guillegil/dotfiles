12 Design decisions

The opinions baked into Cachy Bar. Read these before adding a widget, a theme or a popover — they keep the system coherent across 12 palettes.

01

One vocabulary, every theme

Every palette ships the same 14 accent keys (mauve, blue, peach, teal…) and the same 6-step surface stack. Widgets never reference a hex — they reference a role. That’s why a single widget renders correctly in Mocha and Tokyo Night and Gruvbox.

02

Color carries meaning, not decoration

Green = ok. Yellow = warn. Red = err / destructive. Mauve = AI / accent. Blue = info. Peach = attention / counter. Don’t reach for a new hue when an existing role fits — invent a new accent only if the role is genuinely new.

03

Monospaced by default

The bar lives on a desktop next to terminals — it should feel like family. JetBrains Mono everywhere; tabular numerals for any number that updates (clock, %, temp). Inter only for prose-heavy popovers. Pixel theme swaps to VT323 for the same reason.

04

Glass over the wallpaper, never over an app

The shell is translucent on purpose — the wallpaper bleeds through with blur(28px) saturate(160%). Bar should never sit above a focused window. Hyprland configs reserve the bar’s edge.

05

Popover ≠ overlay

A popover opens next to its widget, dismisses on outside-click, and never dims the screen. The AI overlay is full-bleed with a halo strip on top — use it only for the assistant. Don’t reach for an overlay when a popover will do.

06

Density is configurable, not aesthetic

--pad and --radius are tweakable per user. Aurora users want air; Pillbox users want density. Don’t hard-code spacing — always derive from the tokens so power users can tighten the entire UI with two sliders.

07

Motion is purposeful, never ambient

Six keyframes total. Pulse / viz / ai-talk / blink / marquee / glow. They each report state — recording, listening, playing, focus. No decorative motion. All animations honor prefers-reduced-motion.

08

Icons are 24px stroke, one weight

1.75px stroke at 24px viewBox. Fills only for play/dots/tray glyphs. currentColor so theme tokens drive color. Avoid filled icons in dark themes — they read as buttons, not symbols.

09

The bar reports, the popover does

Bar widgets are read-only at a glance — click them to act. Scroll = small adjust on Volume/Brightness only. Never trap interactive controls in the bar itself; that’s what popovers are for.

10

Plugins are visible only when relevant

Now-playing only when something plays. Idle inhibitor only when on. GitHub PRs only when authenticated. The bar shouldn’t shrink with empty slots. Hide, don’t grey out.

11

Layouts are personality, not utility

Aurora is calm, Pillbox is dense, Cathedral is loud. Pick by personality, not by feature set — all layouts can host all widgets. Switching is one tweak away.

12

Light themes are first-class

Latte / Gruvbox Light / Solarized Light aren’t afterthoughts. They get their own wallpaper variants, recalibrated accents (saturation pushed up), and the same widget vocabulary. If a design only works in dark, it’s broken.

13 Iconography

Stroke-based 24px grid icons. Single weight (1.75 stroke), currentColor, no fills except for filled play / dots / tray glyphs.

14 Wallpapers

Every theme ships at least one wallpaper variant — the desktop backdrop the bar floats over.

15 Tokens

All visual decisions are exposed as CSS custom properties. Drop the snippet below into your AGS project's stylesheet.

/* shape */ --radius: 14px; --radius-inner: 10px; /* widgets inside the shell */ --pad: 8px; /* blur recipe */ --blur: blur(28px) saturate(160%); --blur-popover: blur(36px) saturate(160%); /* motion */ --t-fast: 0.12s; --t-base: 0.15s; --t-morph: 0.18s cubic-bezier(.2,.7,.3,1); /* surfaces (mocha example) */ --bg: rgba(30,30,46,0.82); --bg2: rgba(69,71,90,0.55); --bg3: rgba(88,91,112,0.70); --mantle: rgba(24,24,37,0.92); --text: #cdd6f4; --dim: #a6adc8; /* 14 accent roles — same keys across every theme */ --rosewater: #f5e0dc; --flamingo: #f2cdcd; --pink: #f5c2e7; --mauve: #cba6f7; --red: #f38ba8; --maroon: #eba0ac; --peach: #fab387; --yellow: #f9e2af; --green: #a6e3a1; --teal: #94e2d5; --sky: #89dceb; --sapphire: #74c7ec; --blue: #89b4fa; --lavender: #b4befe; --accent: var(--mauve);
